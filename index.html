1. මූලික සමීකරණ ත්‍රිත්වය

විස්ථාපනය $x$ විට ත්වරණය $f$: $\ddot{x} = -\omega^2 x$.

ẍ = -ω² x  |  v² = ω²(a² - x²)  |  T = 2π / ω

🔥 2. සිරස් තන්තුව ලිහිල් වීම (Slack String Exam Model)

ස්වාභාවික දිග $l$ වූ තන්තුවක තුලිත දිගුව $e = \frac{mg}{k} = \frac{mgl}{\lambda}$ වේ.

  • විස්තාරය a > e විට: අංශුව ඉහළට ගොස් ස්වාභාවික මට්ටම ($x = -e$) පසුකරන ක්ෂණයේදී තන්තුවේ ආතතිය T = 0 (ලිහිල්) වේ!
  • එතැන් සිට අංශුව ගුරුත්වය යටතේ නිදහස් ප්‍රක්ෂිප්තයක් ($a = -g$) ලෙස උපරිම උසට ගොස් නැවත පැමිණේ.
  • මුළු කාලය: $T_{\text{tot}} = 2 \times (t_{\text{SHM}} + t_{\text{gravity}})$.

3. ආනත තලය (Inclined Plane)

ආනත තලය ඔස්සේ ගුරුත්ව සංරචකය $mg \sin\alpha$ බැවින් තුලිතතා දිගුව $e = \frac{mg \sin\alpha}{k}$ වේ.
